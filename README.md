## 📂 Highlight Proyek Data
Berikut adalah beberapa proyek analisis data *end-to-end* yang telah saya kerjakan untuk memecahkan masalah bisnis nyata. Laporan presentasi lengkap dapat dilihat langsung di website portofolio saya.

1. **[Analisis RFM untuk Segmentasi Pelanggan Retail Bisnis]**
   * **Deskripsi:** Melakukan segmentasi dan *profiling* demografi pelanggan bisnis retail menggunakan metode analitik RFM (Recency, Frequency, Monetary).
   * **Dampak:** Membantu mengidentifikasi kelompok pelanggan bernilai tinggi untuk strategi retensi yang lebih tepat sasaran.

2. **[Komparatif Harga Elektronik: Shopee vs Tokopedia]**
   * **Deskripsi:** Mengumpulkan data produk secara otomatis (*web scraping*) dan melakukan uji statistik (*Mann-Whitney U Test*) untuk membandingkan posisi harga di dua platform *e-commerce* terbesar.
   * **Dampak:** Memberikan wawasan intelijen harga (*pricing intelligence*) bagi penjual ritel.

3. **[Faktor yang Memengaruhi Harga Smartphone]**
   * **Deskripsi:** Membangun model Regresi Linear Berganda (Multiple Linear Regression) menggunakan spesifikasi teknis *smartphone*. 
   * **Dampak:** Mengidentifikasi fitur mana (seperti RAM, memori, baterai) yang memiliki pengaruh paling signifikan terhadap harga pasar.

4. **[Analisis Data 54+ Juta Perjalanan Divvy Bikes]**
   * **Deskripsi:** Menganalisis jutaan baris data perjalanan sepeda berbagi (*bike-sharing*) untuk membandingkan pola perilaku antara pelanggan kasual dan pelanggan tahunan.

5. **[Analisis CSAT Ulasan Tomoro Coffee Samarinda]**
   * **Deskripsi:** Mengekstraksi dan mengukur tingkat kepuasan pelanggan (Customer Satisfaction Score) berdasarkan data ulasan teks langsung dari Google Maps.
